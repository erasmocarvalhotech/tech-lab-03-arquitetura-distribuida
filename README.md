# tech-lab-03-arquitetura-distribuida

Laboratório técnico de arquitetura distribuída — projeto de microsserviços para cadastro de produtos e pedidos.

## Objetivo

Explorar padrões de arquitetura distribuída (comunicação entre serviços, persistência isolada por domínio, contratos de API) através de dois microsserviços:

- **Produtos**: cadastro e consulta de produtos.
- **Pedidos**: criação e consulta de pedidos, com referência aos produtos cadastrados.
